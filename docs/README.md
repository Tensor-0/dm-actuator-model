## ⚠️ 两轮结论的差异（务必看第二份）

| 问题 | 第一轮的结论 | 实际 |
|---|---|---|
| MuJoCo 能否表达 τ-ω 曲线？ | ❌ 说"不能，必须自己写 Python" | ✅ **原生 `<dcmotor>` 就能** |
| 落地改动量 | 一大坨（改执行器类型 + 自写 action term） | **XML 换一个标签 + 三个数** |
| 谁的模型更完整？ | 说 Isaac Lab 是标准 | **MuJoCo 原生更全**（多热/LuGre/齿槽/电感） |

**出错根因**：第一轮只查了 `gainprm`/`biasprm`/`dyntype` 这些**通用属性**，
没查 MuJoCo 3.11 新增的**专用元素**。教训：查能力要翻完整文档，不能只看枚举。
