## 提取方法

`tools/extract_curve.py`（可复现）：

1. **轴标定**：检测同色刻度标签文字的行位置，用**最小二乘**把像素 → 物理量。
   不是"取两个端点画直线"——那样会把刻度误差放大。
2. **曲线分离**：按 RGB 分色（各色像素 >800，颜色间不重叠）。
3. **逐列采样**：每 5 px 取该列曲线像素的**中位数**（比均值抗粗线/抗锯齿）。

## ⚠️ 已知问题与可信度

### 1. 两条温升曲线是同一个数据
逐像素比对 `温升.png` vs `温升14Nm.png`：

```
差异像素总数:     238
落在绘图区内:     0        ← 关键
差异区域:         y 51-63, x 693-730（标题文字里 "12"/"14" 那几位数字）
```

**结论**：曲线完全相同，只是标题改了数字。**后者是副本，不是独立工况。**
所以热模型**只有一个工作点**（12 N·m），无法反推热阻的功率依赖。

### 2. 两张图是不同测试协议，别混用

| 图 | 实测行为 | 协议 |
|---|---|---|
| `扭矩效率.png` | 转速随扭矩自然下降 56→38 rpm | **变速加载** → 这才是 τ-ω 来源 |
| `速度效率.png` | 转速恒定 **35.87 ± 0.24 rpm** | **恒转速台架** |

> 一开始曾误把 `Pout/Torque` 当作 ω 使用，结果在低扭矩端数值塌陷
> （Pout→0 时商值失真）。**正确做法是直接用蓝线（转速曲线）**。

### 3. 标定误差估计 ±1~2%
达妙**没有发布原始 CSV**，只能从像素反推。图像为 1000×600、刻度每格约 54~57 px，
分辨率限制带来约 ±1~2% 的读数误差。**若能拿到原始数据应替换。**

### 4. 实测范围（外推风险自评的依据）

```
τ-ω 曲线的实测覆盖：
  扭矩 3.604 ~ 19.351 N·m
  转速 38.0 ~ 56.3 rpm
  角速度 3.982 ~ 5.900 rad/s
```

**超出此范围即为外推**，可靠性迅速下降。

## 自洽性验证

提取结果经三重交叉验证：

| 检验 | 结果 |
|---|---|
| τ-ω 线性度 | **r² = 0.9916**（97 点） |
| 能量法 vs 直接测速 | `Pout/Torque` 反推的 ω 与蓝线直读值同量级（差 ~7%） |
| 恒转速协议判定 | `速度效率.png` 转速标准差仅 **0.24 rpm** → 确认恒速台架 |
| 热模型拟合残差 | RMS **0.66 °C** |
